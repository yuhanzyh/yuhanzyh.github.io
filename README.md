# Yuhan Zhang — Academic Homepage

Personal academic homepage published at:

https://yuhanzyh.github.io/

## Updating the website

Most text content is stored in `site-content.mjs`. Edit that file to update:

- profile and research interests
- latest academic updates
- publications
- conferences and academic footprint
- education
- academic profile links

Images are stored in `public/`. Every push to the `main` branch automatically rebuilds and publishes the website through GitHub Pages.

## Local build

```bash
npm run build
```

The generated static website is written to `dist/`.
